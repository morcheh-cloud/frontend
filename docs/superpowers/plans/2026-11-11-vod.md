# VOD (ویدیو) Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

> تاریخ: 2026-11-11 · وضعیت: پلن (هیچ بخشی ساخته نشده)

**Goal:** بخش VOD در مورچه: آپلود ویدیو، تبدیل به چند کیفیت روی خود مورچه یا هر سرور SSH، بسته‌بندی CMAF (HLS + DASH)، پخش تطبیقی برای عموم مردم با لینک امن و رمزنگاری، و داشبورد آمار — کامل‌تر از VOD ابر آروان.

**Architecture:** فایل اصلی در یک Storage می‌نشیند؛ job `vod-encode` روی یک «Encoder» (خود مورچه با `exec` یا سرور پنل با SSH) با FFmpeg و Shaka Packager خروجی CMAF می‌سازد و مورچه آن را به Storage می‌برد. manifestها را بک‌اند برای هر بیننده بازنویسی می‌کند (توکن، کلید، ترک‌های اضافه)؛ segmentها از سایت proxy نوع `storage` با `secure_link` یا (حالت direct) از خود بک‌اند پخش می‌شوند. پلیر عمومی (`/embed`، `/watch`) با Shaka Player رویداد پخش می‌فرستد و داشبورد از همان‌ها ساخته می‌شود.

**Tech Stack:** Go (Huma, sqlc, goose, `internal/jobs`) · FFmpeg 7.1 (BtbN static GPL) · Shaka Packager v3 · tusd v2 · golang-jwt v5 · beevik/etree · Next.js 16 + TanStack Query · Shaka Player 4 · tus-js-client 4 · (فاز ۳) whisper.cpp، libvmaf، maxminddb · (فاز ۴) MediaMTX، nginx-vod-module.

**Spec:** بخش‌های ۱ تا ۷ همین سند (تصمیم‌های کاربر در گفتگوی 2026-11-11: بیننده‌ها عموم مردم‌اند؛ انکود هم روی خود مورچه و هم روی سرور انتخابی با SSH؛ پیش‌بسته‌بندی CMAF؛ لینک امن + رمزنگاری + واترمارک (DRM واقعی فعلاً کنار گذاشته شد، تصمیم کاربر 2026-11-11)؛ هر چهار فاز؛ همه‌ی موارد «کامل‌تر از آروان»؛ داشبورد آمار).

## ۱. جایگاه در محصول

- بخش جدید **VOD** در گروه Infrastructure منو، بعد از Storage (`vodItem`، آیکون lucide `Clapperboard`)، و در More گوشی. مسیر `/vod`.
- نام در کد: بک‌اند `internal/vod` + `api/vod_*.go`، جدول‌ها `vod_*` و `videos`؛ فرانت `src/app/(panel)/vod/`؛ tag OpenAPI `VOD`.
- **Library** = واحد تنظیمات (یک Storage + پوشه، preset پیش‌فرض، Encoderها، روش تحویل، امنیت، پلیر، webhook). هر workspace چند library دارد؛ هر ویدیو در یک library است.
- **Encoder** = جایی که ffmpeg اجرا می‌شود: `This Morcheh server` (ردیف با `server_id` NULL) یا یک سرور پنل. هر library فهرست Encoderهای مجازش را دارد.
- صفحه‌های عمومی پلیر (`/embed/[id]`، `/watch/[id]`) خارج از panel layout و `AuthGate` هستند (مثل `/login`).

## ۳. پایپ‌لاین انکود

```
source (Storage) ──fetch──► Encoder workdir  /var/tmp/morcheh-vod/<job>/
   ffprobe → Source         ┐
   ffmpeg (یک decode، split) ├─► mezzanine/<rend>.mp4  (fMP4 تمیز، هر rendition)
   ffmpeg thumbs            ┘   thumbs/…
   packager (Shaka)         ──► cmaf/<rend>/init.mp4, seg_%05d.m4s, playlist.m3u8 · manifest.mpd
──put (Morcheh از راه SFTP/local) ──► Storage  <prefix>/<video uuid>/…
```

- **هیچ secret یا کلید Storage روی Encoder نمی‌رود.** ورودی: S3 با `share_links` → URL موقت (`curl`)؛ بقیه → مورچه فایل را با SFTP روی Encoder می‌ریزد. خروجی را همیشه مورچه می‌خواند (SFTP یا محلی) و در Storage می‌نویسد (همان کد transfer موجود).
- اسکریپت‌ها روی stdin به `sh -s` داده می‌شوند (مثل `runLocal`/بکاپ دیتابیس)، هیچ‌وقت روی خط فرمان.
- ffmpeg با `-progress pipe:1 -nostats`؛ پیشرفت = `out_time_us / duration`.
- workdir بعد از پایان/خطا/لغو پاک می‌شود؛ Encoder هنگام setup و هر check، workdirهای یتیم قدیمی‌تر از ۲۴ ساعت را پاک می‌کند.

**قواعد ثابت ABR (همه‌ی presetها):**
- GOP بسته و هم‌تراز: `-g <fps*gop> -keyint_min <fps*gop> -sc_threshold 0 -force_key_frames "expr:gte(t,n_forced*<gop>)"`؛ پیش‌فرض `gop_seconds=2`، `segment_seconds=4`.
- capped CRF: `-crf <crf> -maxrate <bitrate*1.07>k -bufsize <bitrate*2>k`؛ H.264 `-profile:v high -pix_fmt yuv420p -preset medium`.
- بدون upscale: فقط renditionهایی که «ضلع کوتاه» آن‌ها ≤ ضلع کوتاه فایل اصلی است؛ اگر هیچ‌کدام نشد، فقط کوچک‌ترین با اندازه‌ی خود فایل. ابعاد زوج، نسبت حفظ می‌شود؛ ویدیوی عمودی با ضلع کوتاه نام‌گذاری می‌شود (`720p` = عرض 720).
- rotation metadata اعمال می‌شود (ffmpeg autorotate)؛ VFR → `-fps_mode cfr -r <round(fps)>` (سقف 60)؛ HDR (PQ/HLG) → tonemap به SDR با `zscale`+`tonemap=hable` برای H.264.
- صدا: AAC-LC 128k استریو، 48kHz؛ بدون ترک صدا = خروجی فقط ویدیو (master بدون گروه صدا).

**ladder پیش‌فرض (preset `Standard`، H.264):**

| نام | ضلع کوتاه | bitrate (k) |
|---|---|---|
| 2160p | 2160 | 16000 |
| 1440p | 1440 | 9000 |
| 1080p | 1080 | 5000 |
| 720p | 720 | 2800 |
| 480p | 480 | 1400 |
| 360p | 360 | 800 |
| 240p | 240 | 400 |

CRF پیش‌فرض 23. presetهای داخلی دیگر: `Fast` (تا 720p، `-preset veryfast`)، `High quality` (CRF 20، `-preset slow`). HEVC/AV1 (فاز ۳) = همان ladder با ضریب 0.6 / 0.5.

**چیدمان در Storage:** `<prefix>/<video uuid>/` → `source/<نام فایل>`، `mezzanine/<rend>.mp4`، `cmaf/<rend>/…`، `cmaf/audio_<lang>_<n>/…`، `text/<lang>.vtt`، `manifest.mpd`، `thumbs/poster.jpg|sprite_<n>.jpg|thumbs.vtt|preview.webp`، `download/<rend>.mp4`.

## ۴. تحویل و امنیت پخش

- هر ویدیو یک `public_id` دارد (12 کاراکتر base62 تصادفی) که در همه‌ی آدرس‌های عمومی است؛ uuid فقط نام پوشه است.
- **manifestها از بک‌اند** (`/vod/p/{public_id}/…`، بدون session): master از روی DB ساخته می‌شود؛ playlistهای هر rendition و MPD از Storage خوانده می‌شوند (Redis، 10 دقیقه) و آدرس segmentها مطلق و امضاشده می‌شوند.
- **segmentها** زیر `<base>/s/<tok>/<exp>/<video uuid>/…`:
  - `proxy`: `<base>` = دامنه‌ی سایت proxy نوع `storage` که مورچه برای library می‌سازد (nginx `secure_link`، کلید کش = مسیر بدون توکن).
  - `direct`: `<base>` = `<VOD_PUBLIC_URL>/vod/p/{public_id}`؛ بک‌اند همان امضا را چک و از Storage با Range پخش می‌کند (dev، Storage غیر S3، تیم‌های کوچک).
  - امضا (سازگار با nginx): `tok = base64url_nopad(md5(exp + "/" + videoUUID + " " + secret))`. `exp` = `ceil_to_hour(now + duration + 6h)` تا آدرس‌ها یک ساعت ثابت بمانند (کش CDN) و ویدیوی بلند وسط پخش منقضی نشود.
- **دسترسی (`access`، library با override هر ویدیو):** `public` (بی‌توکن)، `signed` (توکن JWT HS256 که بک‌اند مشتری با `signing_key` کتابخانه می‌سازد: claims `vid`=public_id، `exp`، اختیاری `ip`، `sub` = شناسه‌ی بیننده برای واترمارک/آمار، `dl`=اجازه‌ی دانلود)، `private` (فقط داخل پنل با session).
- `allowed_domains`: روی manifest/player.json، `Referer`/`Origin` چک می‌شود؛ صفحه‌ی embed هدر `Content-Security-Policy: frame-ancestors <دامنه‌ها>` می‌گیرد. خالی = همه.
- **Player domain** (فاز ۲، اختیاری): یک سایت proxy نوع `proxy` که `/embed/*`، `/watch/*`، `/_next/*` را به frontend و `/vod/p/*`، `/vod/beacon` را به backend می‌برد و بقیه را `deny` می‌کند، تا پنل روی دامنه‌ی عمومی دیده نشود.

## ۵. داشبورد آمار

- تب **Dashboard** پیش‌فرض `/vod` است (`range` 24h/7d/30d/90d و `library` در URL)، روی ماژول مشترک `src/components/insights/` و `src/components/charts/time-chart.tsx`.
- **کاشی‌ها:** Views، Watch time، Unique viewers، Avg view duration، Completion rate، Watching now، Startup time (p50)، Rebuffer ratio، Error rate — همه با مقایسه با دوره‌ی قبل.
- **نمودارها:** views و watch time در طول زمان؛ بیننده‌ی هم‌زمان (۳۰ دقیقه‌ی اخیر، هر ۱۰ ثانیه)؛ QoE در زمان (startup p50/p95، rebuffer ratio، error rate)؛ توزیع کیفیت پخش‌شده؛ Top videos؛ دستگاه/مرورگر/سیستم‌عامل؛ (فاز ۳) کشور، referrer، پهنای باند تحویل‌شده.
- **بخش محتوا و انکود:** تعداد ویدیو آماده، ساعت محتوا، حجم Storage و رشد آن، دقیقه‌ی انکودشده در روز، سرعت میانگین (×realtime)، صف و انکودهای ناموفق، بهره‌وری هر Encoder.
- **هر ویدیو** (تب Analytics صفحه‌ی ویدیو): همان کاشی‌ها + (فاز ۳) منحنی ماندگاری (drop-off هر ۱٪)، heatmap جاهای تکرار/پرش.
- داده: جدول `vod_sessions` (یک ردیف برای هر پخش، با beacon به‌روز می‌شود، `VOD_SESSION_HISTORY` پیش‌فرض 90 روز) + `vod_stats_daily` (برای همیشه). بازه‌های ≤90 روز از sessions محاسبه می‌شوند.
